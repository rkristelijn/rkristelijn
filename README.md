### [`@flupkejs/*`](https://www.npmjs.com/org/flupkejs) — native drop-in replacements
A family of **166 packages** that replace popular dependencies with lean, native
ES2020+ implementations (no transitive bloat). Drop-in replacements for `axios`,
`lodash`, `moment`, `dotenv`, `uuid`, `qs`, `chalk`, `ms`, and many more — one
command via [`@flupkejs/cli`](https://www.npmjs.com/package/@flupkejs/cli):
"one command, safer dependencies."
